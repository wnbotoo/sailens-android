### 3.2 门槛

在 S 组上算，**合并 S 的全部会话**（只算生命周期完整记录的会话）；C 组的结果同时报告，C 也必须满足（现在满足）。
四个原则：

- **时长不取自被评分的录制。** 第 1 版先用本段录制的生命周期按措辞取时长，再拿它预测同一段的结束时刻；一句只说完过一次
  的措辞会被"预测"到毫秒不差（第 1 轮评审 P1-1），69 ms 的 done 误差并不独立。现在：S 只用**冻结的 C 时长表**
  （`SpeakerDurations.FROZEN_C`：C 全部 14 段按措辞的中位数，再回退到 D1.7 表加 45 ms 偏移、最后默认 1.4 s），S 自己的生命周期只用于
  评分；C 上的数字用**留一法**（每段的时长取自其余 13 段），与 S 上同样独立。第 3.1 节的数字就是这样得到的。
  一段录制属于 C 还是 S，按冻结的会话清单（`D18Sets`，分配表里录好的 14 + 13 个会话 id）判断，**不看 `SEALED` 标记**：
  标记只管能不能看（冻结后按录制计划可以删掉它），删掉它不能让 S 变成时长表的来源（第 2 轮评审 P1-1）。两个清单之外的
  录制，喇叭模型不评分。C 全部在场时，C 合并出的表必须等于冻结表，否则测试失败。
- **实验臂的"以为说完了"更严。** 反事实评估里，实验臂"模型以为说完了、其实没说完"会把退步藏起来（不安全），所以完整说完
  的精确率、CRITICAL 的"模型接收/说完而设备没有"单独设门槛。另一个方向（基线臂"以为没说完"）第 1 版以为只是保守，评审
  指出它会让受保护阶段从 M5 里消失；第 2 版的 M5 改用设备的真实完成作保护集合（§4.2），这个方向因此变成保守的。
- **门槛低于 C 的值，留出抽样误差。** S 预计约 2 000 次给出、约 550 次接收、约 1 100 次 CRITICAL 给出；每个门槛离 C 的
  留一法数值约 2.5–3.5 个标准误（按 S 的预计数量算）。第 1 版的门槛是照不独立的数字定的；第 2 版按留一法的数字重定，
  A2、A3、A4、A6–A8、A11 因此放宽（S 打开之前按 R6 修订：理由和 C 证据就是本节和第 3.1 节）。
- **时序门槛要明显小于 M5 的 0.5 s 容差**，否则 M5 的"不晚于基线 0.5 s"没有意义。

"以为说完了"由 A4、A7 约束。

**A12 闭环检查。** 3.1 是开环的：给出流来自设备。反事实运行是闭环的：模型的拒绝会撤回冷却，从而改变之后的给出。开环一致
不等于闭环一致。所以加一项：用 `SPEAKER_MODEL` 送达假设、**录制时的机高（1.2 m）**、录制时的配置和第 3.2 节的时长规则
（S 用冻结的 C 表，C 用留一法），重跑今天的策略，与设备按 §4.2 的保护集合 P（R9 的参考队列）逐个阶段对比：

### 3.3 事先写明的排除

只有下面这些排除，没有别的。排除之后，模型在这些情况下就**不能用**：相关阶段在验收里只能用真机证据，反事实里算"不可判定"（§4.2：除非能按那里唯一的规则化解，一律按退步计）。

| # | 排除 | 规则 | C 组里出现 |
|---|---|---|---|
| X1 | 生命周期不完整的会话 | 证据不是 RECORDED（没有、有丢弃或未对账、读屏会话）：整段不进校准，模型不用于这段 | 0 段 |
| X2 | 证据冲突的逻辑提示 | 不进校准，也不进验收；超过 S 给出数的 1% 就判校准不过 | 0 |
| X3 | 引擎失效与重启的窗口 | 录制不给模型引擎就绪状态。从某一代引擎的第一条 `error`、`unknown_terminal`、"引擎未就绪"（`engine_not_ready`）或"speak 出错"（`speak_error`）拒绝、或因 `speak_failed` 清掉队列开始，到下一代引擎第一次 `started` 为止（没有下一代就到会话结束），再顺延到设备和模型的喇叭**都空闲**为止，这段时间内的给出全部排除；超过 S 给出数的 2% 就判校准不过 | 0（全部是第 1 代） |
| X4 | 录制结束时还没有结果的提示 | 只不进时序误差；接收/拒绝照常算 | S 报告里单独计数 |
| X5 | 系统通知或描述占着喇叭时的给出 | 从它提交到它最后一条生命周期记录（或提交 + 时长，取较晚者），再顺延到设备和模型的喇叭**都空闲**为止，之间的给出不评分；超过 S 给出数的 2% 就判校准不过 | 0（C 里没有描述和通知） |

X5 是第 2 版新加的。模型仍然排队通知和描述，但它们的时长只能取自这段录制自己的生命周期（文本各不相同，没有表）。按
第 3.2 节，被评分的预测不能用被评分录制的生命周期，所以这段时间里的给出不评分，只用来让喇叭在正确的时刻空出来。
第 3 版：X3、X5 的窗口都顺延到**设备和模型的喇叭都空闲**的那一刻（第 2 轮评审 P1-2 的反例：设备的通知 1 990 ms 结束、模型的

都成立（第 5 版，第 4 轮评审 P1-1：第 3 版写的"冷却上限 8 s"是错的，8 s 只是缩放的上限，基础冷却更长的不受它限制）：
- 冷却表里的每一条记录，都已超过它那个 key 在任何事件、任何缩放下可能起作用的最长冷却：key 有专用冷却的按专用冷却，否则按
  用这个 key 的事件类别的冷却；缩放后的上限是 max(基础冷却, 8 s)，所以 `GROUND_UNRECOGNIZED` 要 60 s、传感器提示 15 s、道路
  警告和红绿灯 12 s。key 属于哪个类别，按 `EventGenerator`/`EventMerger` 生成 key 的规则定，并用测试列举全部 key 前缀；归不了
  类的 key 按冷却表里最长的 60 s 算。

- 撤销日志里没有还可能被撤销的记录。
做不到就按 §4.2 计。PR-1b 要有两个测试："喇叭已空闲、冷却仍不同"，以及"静默 21 s 后，曾记录和已撤回的 60 s 冷却仍让同一条
后续提示一边被压住、一边放行"（判据必须到 60 s 之后才放行）。

### 3.5 已知局限（不影响门槛，但限制模型的用途）

## 4. (b) D2–D4 成功门槛（Q6）

### 4.1 通用规则

- **R1 在哪里判。** 所有门槛都在 S 上判，合并 S 全部会话；每段的数字也报告。C 上的数字只作参照。
- **R2 判哪个组合。** 判的是**准备上线的开关组合**（PR-4 要翻的全部开关同时打开）。每个开关单独的运行也跑，只作诊断，
  不另设门槛（避免多次比较）。
- **R3 两臂怎么跑。** 基线臂 = 今天的策略（det 优先的新开关全关），实验臂 = 上线组合；两臂都用 `SPEAKER_MODEL` 送达、
  录制时的配置（**接地点开关保持开**，胸前手持）、回放注入的轨迹 id；两臂的轨迹出生序列必须一致，否则不给配对指标。
- **R4 机高。** 两臂的策略和距离测量都用 **1.15 m 预设**（用户真实持机，方案 §4）；M4、M5 在 1.05 m 和 1.25 m 上也必须
  通过；M1 只在 1.15 m 上判。（第 1 节：今天的报告用的是 1.2 m；A12 闭环检查用 1.2 m，因为它要和设备比。）
- **R5 样本量下限。** 主指标的分母（能夹定越界的危险数，或进入该阶段的危险数）< 20 时，记为"不可判定"——**不可判定
  就是没通过**，相应的开关不翻。按 C 的数量估计（S 时长约为 C 的 88%），下面每个主指标的分母在 S 上预计 ≥ 30。
- **R6 修订。** S 打开之前，门槛只能用新的提交修订：写明理由和所用的 C 证据，经 GPT 评审和用户同意，更新分配表的那一行。
  S 打开之后不能修订；S 上的结果不能拿回去调参数；调了，相应的验收就作废，要重录一批封存组。
- **R7 S 只打开一次**：在 `SpeakerModel` 版本、PR-1b / PR-2 / PR-3 的代码和全部参数都冻结之后。参数冻结另记一行（Q14）。打开时的验收入口按 `D18Sets.SEALED` 核对：13 段全部在场、都完整、都精确回放，缺一段或多一段就不判。
- **R8 报告置信区间。** 比例类指标按点估计判，同时报告 Wilson 95% 区间（不用于判定）。
- **R9 参考危险队列：两臂按同一个集合评分。** 第 1 版只固定了 NEAR 的定义。评审指出，今天的评估器按危险**首次阶段出现时**
  的类别和方位归类：公制门槛让一个危险更早出现，它就可能在侧方先出现、被归成 `person/side`，从前方的分母里消失。所以：
  - 危险身份 = 轨迹（回放注入的出生序 id）；两臂和设备的精确回放，出生序列必须一致（R3）。
  - **参考队列 = 设备的精确回放**（今天的策略，C 报告用的那次运行）里出现过的危险，类别和方位按那次运行的规则定，冻结。
    实验臂改变出现时间，不改变一个危险属于哪一类。
  - 分母按参考队列：M1 的"前方行人首次"= 参考类别为 `person/front` 的危险；M2 的 NEAR 分母 = 在参考运行里按今天的定义
    出现过 NEAR 阶段的危险；M5 的 P 也用这个队列。实验臂对同一危险完整说完相应措辞（首次：任何说到它的提示；NEAR：NEAR
    措辞），不论在实验臂里被归到哪个方位，都算。
  - 越界能不能夹定、先后不确定、终点不可知，只由这条轨迹自己的新鲜距离样本决定（`LeadTime`），与策略无关；两臂和参考
    运行用同一套样本。
  - 实验臂新出现、参考队列里没有的危险，不进 M1、M2、M5 的分母，另外报告；它们受 M4（C4、C5、C8）约束。
  - 实现随第一个反事实 PR（PR-1b）提交，并且必须把评审给的反例写成测试：同一轨迹在实验臂先在侧方出现，参考运行把它归为
    `person/front`，结果仍按 `person/front` 计。
  - R9 只回答"参考队列里的危险，实验有没有说得更好"。实验臂新出现的危险另报、受 M4 约束，只验证了它们的部分误报性质，
    **不证明它们的召回或提前时间**；这一点写进验收结论，不当作通过的证据。
- **R10 实验臂的完成按稳健判定（第 4 版）。** 模型的每句结束时刻都有误差（C 上留一法 |done| p95 70 ms、p99 137 ms、最大
  752 ms）。一句话在下一个提示到来前几十毫秒说完，模型判"说完"，真实里可能被打断，或者反过来挡住后面的一句。A4、A7 是总体
  比例，排除不了某一个阶段的这种假完成。第 3 版用四次均匀扰动，第 3 轮评审给了反例：A、B、P 三句各相隔十几毫秒，全部加长时
  B 被拒、反而给 P 让出时隙，只有 B 一句长 40 ms 时 P 被挡住——四次均匀扰动都判保住。所以改为**逐句独立的误差**：
  - 每句的结束时刻是一个区间 [名义 − ε, 名义 + ε]，ε = 150 ms，各句互相独立；D1.7 回退的措辞 ε = 300 ms。
  - 按喇叭模型的仲裁往前推。每当一步仲裁要拿某个时刻和某句的结束时刻比、而区间跨过这个时刻（"已经说完"和"还在说"都可能），
    就分成两支，各自带着收窄后的区间继续。这样，ε 以内任何一种独立误差能走到的结果都会被走到（`SpeakerRobustness`）。
  - 实验臂的一个阶段算"完整说完"，必须在**每一支**里都完整说完；三个指标各自的截止分别冻结（第 5 版，第 4 轮评审 P1-2）：
    - **M5**：每一支都在 t_dev + 0.5 s 之前说完，才算保住；否则不可判定（§4.2，按退步计）。
    - **M1**（C1–C3）：用**所有分支里最晚的完成时刻**，按 `LeadTime` 原来的定义分类；分类为"之前"（BEFORE）才算成功。
    - **M2**（B1–B3）：保持原来的完成率定义——每一支里同一危险的 NEAR 措辞都完整说完，就算成功，**不附加任何距离或越界
      条件**（Q4：M2 用完成率判，不用提前时间）。越界之后才说完的，仍算 M2 成功。
    有一支被拒或被打断就不算。
  - 状态相同的分支合并。同时存在的分支超过 64 支，涉及的阶段一律不可判定。开环下 C 的 2 372 条给出在 ε = 150/300 ms 下都没碰到
    这个上限（第 4 轮评审核对）；闭环要在 C 上完整预演，触顶照样阻断，不能看了 S 再调。
  - 闭环（反事实两臂）里，每一支都要重跑决策（冷却记录、撤回和之后的给出），分支只在喇叭状态**和**冷却状态都相同时合并。
    这部分随 PR-1b 实现，并把 A/B/P 反例写成闭环测试（P 不得判为保住）。开环的核心和 A/B/P 的开环测试已在本 PR
    （`SpeakerRobustness`、`SpeakerRobustnessTest`）。
  - **ε 是覆盖范围，不是误差上界。** C 上两边都说完的 472 句里，有 4 句（0.8%）结束误差超过 150 ms；S 上由 A13 检查。误差
    超出 ε 的句子仍可能让某个阶段被误判为保住，这是剩下的风险，验收结论里写明。A13 是时序漂移的
    条件门槛，**不能解释为"98% 的提示或危险受 R10 保护"**，也不豁免任何已知的真实退步。
  - 基线臂不分支：它只用来判断模型能否复现设备，复现不了的阶段本来就算不可判定。这只会让实验显得更差，门槛不改。

### 4.2 M5 不倒退（对上线组合）

第 1 版让两臂都用模型、保护集合取自模型基线臂。评审指出：模型在基线臂漏判一个设备其实说完了的阶段，这个阶段就不进保护
集合，实验臂再丢掉它也不算退步；两臂用同一个模型，误差并不保证抵消。所以改成下面的规则。

- **保护集合 P 来自设备，不来自模型。** P = S 上设备完整说完的每个 CRITICAL 阶段和 NEAR 阶段（CRITICAL 含"前方不通"和
  镜头遮挡的唯一阶段），加上前方行人的首次阶段（行人首次至少是 HIGH，不一定进入 CRITICAL）。危险和阶段按 R9 的参考队列；
  阶段的完成时刻 t_dev = 设备的首次完整说完时刻。模型无论怎么判，P 里的阶段都不会消失。
- 对 P 的每个阶段，两臂都在模型下闭环运行（R3）：
  - **基线臂复现**：基线臂完整说完这个阶段，且首次完成时刻与 t_dev 相差 ≤ 0.5 s；
  - **实验臂保住**：实验臂**稳健地**（R10）完整说完这个阶段，即每一支里首次完成时刻都 ≤ t_dev + 0.5 s。
  - 实验臂保住 → **保住**。
  - 实验臂没保住、基线臂复现 → **退步**（模型在这里复现了设备，差别只能来自实验）。
  - 实验臂没保住、基线臂也没复现 → **不可判定**：模型在这里不可信。唯一的化解规则：存在一个时刻 t0（不晚于这个阶段在设备
    记录里第一次给出），设备、基线臂、实验臂三方在 t0 时喇叭都空闲，并且从 t0 到 t_dev + 0.5 s 三方送到喇叭的**全部输入**逐条相同：每条提示的时刻、措辞、优先级、过期时刻和喇叭 rank
    （PR-1b 之后），以及通知、描述、取消、重排、引擎就绪的每一项（设备一方以生命周期记录为准）。这时实验在这段时间里没有
    改变喇叭上的任何事，设备的结果就是实验臂的结果，算保住。任何一项无法从记录证明相同，就不化解（第 2 轮评审 P2-1：
    只比时刻、措辞、优先级时，过期时刻不同就能让结果相反）。**其余的
    不可判定一律按退步计**（阻断），不能靠人工审查化解。
- 只被接收、没说完的不能抵账；另一个危险或更早的一次普通提示也不能抵账（方案 §4）。
- **门槛 M5**：
  - 前方车辆、前方行人的 CRITICAL 阶段和前方不通：**0 条退步**（含按退步计的不可判定）；
  - 全部范围合计：退步 ≤ max(2, |P| 的 1%)；
  - 每条退步和每条不可判定都做 contact sheet 人工审查并写进验收记录；审查只用于理解原因，**不能豁免**。
- 各类条数都报告：保住、退步、不可判定（化解的 / 按退步计的）。另外报告"模型基线臂 vs 实验臂"的同一比较，只报告，不判。
- 方向：实验臂里模型"以为没说完"只会多算退步（保守）；"以为说完了"会藏住退步，由 A4、A7 约束；基线臂的漏判只会多出
  不可判定（保守）。
